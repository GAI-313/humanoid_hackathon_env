ピックR1！　チーム紹介

【約60秒】仕組みはシンプルです。R1のカメラでQRを読み、箱IDと区画を判定して、JSONのイベントとして送ります。イベントは2か所に届きます。ひとつはロボット制御で、分類先の区画へ歩かせます。もうひとつはダッシュボードで、読取・移動・到着・エラーをリアルタイムに表示します。さらに、Geminiの画像認識で箱の見た目も照合し、誤出荷を二重にチェックします。

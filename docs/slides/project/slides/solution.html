ピックR1！　チーム紹介

【約60秒】ピックR1は、人型ロボットR1が倉庫のピッキングを手伝う仕組みです。流れは4ステップ。1、箱に貼ったQRコードをR1の目で読み取る。2、QRの内容から分類先の区画を判定する。3、その区画へ歩いて向かう。4、作業の記録を、誰が・何を・どこへ・いつ、という形でダッシュボードに表示します。想定外のQRを読んだときは、誤出荷アラートで警告します。
